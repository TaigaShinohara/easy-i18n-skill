# ストア掲載文の扱い

## 前提

- 掲載文はアプリ内翻訳とは別の仕組みであり、別の場所で管理される。アプリのカタログを翻訳しても掲載文は自動では変わらない。例外は Chrome Web Store の名前と短い説明だけで、これはパッケージの `_locales` から読まれる。

- 掲載文は最も費用対効果が高い翻訳である。見つけてもらえるかと入れるかどうかを決めるためである。

## ストアごとの置き場所

- Google Play では Play Console でタイトルと短い説明と長い説明とスクリーンショットを言語別に管理する。未登録の言語では自動翻訳された掲載文が見える場合があるが、品質は保証されない。アプリ内文字列の自動翻訳は別の任意機能であり、複数形の扱いは未確認のため使う前に1件で試す。

- App Store では App Store Connect で名前とサブタイトルとキーワードと説明と更新情報を言語別に入力する。自動翻訳はない。キーワードは単語の直訳ではなく、その言語での検索意図に合わせて選ぶ。

- Chrome Web Store では名前と短い説明はパッケージ側から自動で切り替わり、長い説明とスクリーンショットはダッシュボードで言語別に手入力する。

## 進め方

- 正本は `store/<locale>/listing.md` に置く。ストア画面へはそこから貼る。画面で直接直したら正本にも戻す。

- 優先順位はタイトル、短い説明、スクリーンショットの文字、キーワード、長い説明の順である。長い説明は検索への効き方がストアで違うため最後でよい。

- 文字数制限はストアごとに違うため、素材パックを作る段階で store_listing_pack の仕様と合わせて確認する。翻訳で膨らむ分を見込み、制限の8割を目安に収める。

- スクリーンショットの文字も翻訳対象である。画像の中の英語が残ると掲載文だけ訳しても半端になるため、撮影し直すか文字なし画像に寄せるかを言語ごとに決める。
